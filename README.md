# TRADER PRO CHEMLAL

A Vite + React trading dashboard starter for deployment on Vercel.

## Run locally

```bash
npm install
npm run dev
```

## Deploy

Import this GitHub repository into Vercel. Framework preset: Vite. Build command: `npm run build`. Output directory: `dist`.

## Important integrations

The current version includes a TradingView chart widget and a dashboard UI scaffold. It does **not** yet include authenticated live broker data, MT5 execution, AI analysis, or a secure password backend. Do not put API keys or passwords in client-side code. Configure secrets as Vercel Environment Variables and implement server-side authentication before enabling access control.
